# Machine Learning with Python (IBM AI Engineering)

This repository contains my hands-on lab code, algorithms, and projects completed as part of the **Machine Learning with Python** course offered by **IBM** on Coursera (Course 1 of the IBM AI Engineering Specialization).

---

## 📚 Curriculum Breakdown & Lab Files

### 🔹 Module 1: Introduction to Machine Learning
- Overview of ML algorithms, lifecycle, and scikit-learn basics.

### 🔹 Module 2: Linear and Logistic Regression
- `Simple_Linear_Regression.ipynb` — Predicting vehicle CO2 emissions using simple linear regression.
- `Multiple_Linear_Regression.ipynb` — Estimating fuel consumption and emissions with multiple feature inputs.
- `Logistic_Regression_with_Python.ipynb` — Customer churn prediction for telecommunications using logistic classification.

### 🔹 Module 3: Building Supervised Learning Models
- `Decision_Trees.ipynb` — Drug classification based on patient demographic data.
- `Regression_tree_taxi_tip.ipynb` — Predicting taxi tip amounts using Decision Tree Regressors.
- `Diabetes_prediction_model.ipynb` — Binary classification for diabetes risk using Support Vector Machines (SVM).
- `rick_vs_mine.ipynb` — Submarine rock vs. naval mine classification using sonar signals.

### 🔹 Module 4: Unsupervised Learning *(In Progress)*
- *Upcoming Notebooks:* K-Means Clustering, DBSCAN, HDBSCAN, and Dimensionality Reduction (PCA, t-SNE, UMAP).

### 🔹 Module 5: Evaluating & Validating Models *(In Progress)*
- *Upcoming Notebooks:* Cross-validation, Regularization (Ridge/Lasso), Scikit-Learn Pipelines, and Hyperparameter Tuning with `GridSearchCV`.

### 🔹 Module 6: Final Projects *(In Progress)*
- **Practice Project:** Titanic Survival Prediction using pipelines and tuning.
- **Capstone Project:** Rainfall Prediction Classifier using historical weather data.

## 🚀 Getting Started

1. **Clone the repository:**
   git clone https://github.com/harinathreddy-ai/Machine-Learning-with-Python.git
   cd Machine-Learning-with-Python

2. **Install dependencies:**
   pip install numpy pandas scikit-learn matplotlib seaborn jupyter

3. **Launch Jupyter:**
   jupyter notebook
